# algae-env-feature-correction

环境状态驱动的藻类荧光特征校正验证仓库。

## 目标

验证同步环境参数是否能够作为**荧光测量补偿变量**，把不同环境状态下的有限通道荧光特征投影到统一参考状态，并在严格的站点外验证中改善独立光学/生物量指标的泛化性能。

本仓库当前**不主张已经证明藻类识别准确率提升**。现有外采站点缺少同步藻群真值，因此第一阶段只验证：

1. 环境变量是否对荧光-叶绿素映射提供稳定的增量信息；
2. 这种增量信息能否转化为显式的特征校正算子，而不是简单特征拼接；
3. 校正收益是否能够通过留站验证、置换检验和极端站点敏感性分析。

## 当前数据角色

- **F97 Pro 外采数据**：约 29 个有可用 EEM 的真实站点；同步记录盐度、pH、水温、DO、浊度、ORP、叶绿素及部分营养盐。用于环境补偿可行性验证。
- **F-4700 受控藻实验**：8 种藻纯藻与多组分混合样。用于既有有限通道藻群识别基线，不用于证明环境补偿效果。
- **原始数据不提交 GitHub**：仓库仅保留接口、配置、代码和结果摘要，避免泄露未发表实验数据及潜在专利细节。

## 核心假设

设有限通道荧光特征为 `x`，环境状态为 `z`，参考环境状态为 `z0`。对第 `j` 个荧光特征构造环境响应函数：

```text
x_corr[j] = x[j] - (g_j(z) - g_j(z0))
```

其中 `g_j` 必须仅在训练站点中拟合，测试站点不可参与任何参数估计。

第一阶段优先单变量审计，顺序建议：

```text
salinity -> pH -> temperature -> DO -> ORP -> turbidity
```

浊度仅作为对照变量，不作为首要专利创新点。

## 验证原则

- 外层按站点留出，禁止同一站点信息泄漏；
- 所有标准化、环境补偿函数、特征选择和回归参数仅在训练集拟合；
- 首先比较单环境变量，避免小样本下“全部参数一起上”导致过拟合；
- 叶绿素作为独立验证终点时，不得同时作为补偿输入；
- 必须加入环境变量随机置换负对照；
- 必须报告移除极端站点后的敏感性结果；
- 只有显式校正方法稳定优于荧光基线，才进入专利实施例阶段。

## Go / No-Go 判定

建议在正式跑数前冻结以下判定条件，避免事后挑结果：

- 留站交叉验证 MAE 相对基线改善至少 15%；
- `R²` 同方向改善；
- 环境变量随机置换检验 `p < 0.05`；
- 移除任意 1–2 个极端站点后，改善方向不反转；
- 校正收益不能只来自“环境参数直接预测叶绿素”，必须证明其与荧光特征存在交互/校正价值。

上述阈值是**研究阶段门槛**，不是当前已经获得的实验结论。

## 当前专利定位

若第一阶段通过，候选技术主题应优先表述为：

> 基于环境状态约束的多波长藻类荧光特征校正方法及传感系统

而不是“多参数机器学习藻类分类”。详见 `docs/PATENT_EVIDENCE_BOUNDARY.md`。

## P01 实际运行状态

P01 已按 `config/p01.yaml` 完整运行并提交结果。当前决策为 **RED**：29 个有效 F97 Pro 站点的盐度显式校正使 LOSO MAE 从 7.273 增至 8.283（相对恶化 13.88%），1000 次置换检验 p=0.643，极端站点敏感性也不稳定。该结果不支持进入环境补偿专利主路线；详见 `P01_DECISION.md` 和 `reports/P01_environment_correction_audit.md`。
