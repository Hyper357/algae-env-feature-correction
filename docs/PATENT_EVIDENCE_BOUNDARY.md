# 专利证据边界

## 当前可以验证/表述

- 真实海水环境状态与有限通道荧光响应之间存在可检验的关联；
- 某些环境变量可能对荧光-独立叶绿素映射提供跨站点增量信息；
- 可构造显式环境状态校正算子，将荧光特征映射至统一参考状态；
- 校正方案可以通过严格留站交叉验证、置换负对照和敏感性分析验证。

## 当前不能直接声称

- 盐度、pH 或温度已经被证明提高藻种识别准确率；
- 现场 29 个站点已经具有藻种/藻群真值；
- F97 与 F-4700 已完成跨设备定量标定；
- 环境参数与某具体藻种之间存在因果关系；
- 叶绿素、盐度、pH 等简单拼接到分类器即构成创造性。

## 候选独立权利要求逻辑

```text
获取待测水样的多波长荧光响应；
同步获取至少一种水体环境状态参数；
依据环境状态参数确定相对于参考环境状态的特征漂移量；
利用特征漂移量对至少一个荧光强度特征、归一化特征或比值特征进行校正；
得到参考环境状态下的校正荧光特征；
将校正荧光特征用于藻类光学群组识别、浓度/生物量估计或异常检测。
```

## 创造性重点

创新点不应写成“多参数传感器”，而应集中在：

1. 环境变量如何进入补偿链；
2. 补偿作用于哪些荧光特征；
3. 如何定义参考环境状态；
4. 如何得到通道/特征特异的漂移量；
5. 校正前后产生什么可量化技术效果；
6. 校正机制与已有浊度散射补偿、温度常规补偿的区别。

## 现阶段专利题名候选

> 一种基于环境状态约束的多波长藻类荧光特征校正方法及传感系统

题名仅为研究阶段工作名，不应在完成查新和数据验证前冻结。
